# DevChar Roadmap

What's planned, in rough priority order.

---

## v0.2.0 — Platform polish
- [ ] Auto-detect platform and adjust context budget automatically
- [ ] Full Windsurf MCP bridge
- [ ] Codex CLI compatibility testing and documentation
- [ ] `/chat --since <date>` flag for time-scoped questions

## v0.3.0 — New commands
- [ ] `/summary <file>` — plain-English overview of any file
- [ ] `/deps` — explain the project's dependency tree in plain English
- [ ] `/compare <file1> <file2>` — explain the differences between two files
- [ ] `/coverage` — identify areas with no tests

## v0.4.0 — Session features
- [ ] `/export` — save the current Q&A session as a markdown file
- [ ] Cross-session memory (opt-in, stored locally)
- [ ] `/history` — list questions asked in this session

## v1.0.0 — Stable
- [ ] All platforms fully supported and documented
- [ ] Comprehensive test suite of example sessions
- [ ] Auto-install script (`npx devchar install`)
- [ ] Landing page with live demo video

---

Have an idea? Open an issue — community suggestions are the best source of roadmap items.
